# .emacs.d

My emacs configuration. A lightweight but heavily customized config. As much as possible functionality is broken out into separately loaded modules. Built-in libraries are used wherever possible over external dependencies. This config is pretty stable on Linux / WSL2 but has some rough edges on Windows.
